# Citrine Client downloads

Download the latest **Citrine Launcher** from the [Releases page](../../releases/latest).

1. Download `CitrineLauncher-Setup-x.y.z.exe`.
2. Run it. If Windows says "Windows protected your PC", click **More info → Run anyway**
   (the installer isn't code-signed yet).
3. Open **Citrine Launcher**, pick a version and press **Play**.

The launcher updates itself when a new version is released.
