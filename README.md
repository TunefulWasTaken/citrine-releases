# Citrine Client

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**

Citrine Client is a free PvP client and launcher for Minecraft: Java Edition (1.8.9, 1.21 to 1.21.11, 26.1.2 and 26.2).
You need to own Minecraft: Java Edition to play.

- **Made by:** TunefulWasTaken
- **Contact:** citrineclient1@gmail.com

## Download

Get the latest **Citrine Launcher** from the [Releases page](../../releases/latest).

**Windows**
1. Download `CitrineLauncher-Setup-x.y.z.exe`.
2. Run it. If Windows says "Windows protected your PC", click **More info → Run anyway**
   (the installer isn't code-signed yet).
3. Open **Citrine Launcher**, pick a version and press **Play**.

**Mac**
1. Download `CitrineLauncher-x.y.z-mac.dmg`.
2. Open it and drag **Citrine Launcher** into **Applications**.
3. The first time, right-click Citrine Launcher → **Open** → **Open** (it isn't notarized by Apple yet).

The launcher updates itself when a new version is released.

## What it does

- Starts Minecraft with the Citrine mod and free performance mods (from Modrinth).
- Plays with your Microsoft account through the official Minecraft Launcher.
- Downloads Minecraft only from Mojang's own servers.
- Free, with no paid features.
